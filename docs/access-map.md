## Stack
- Next.js 16 + React 19 + TypeScript strict
- Tailwind v4 + shadcn/ui
- Google Apps Script (CMS API)
- Vercel (deploy automático desde main)

## CMS — Pestañas del Sheet
- Config: configuración global (WhatsApp, email, teléfono)
- Manufactura_Servicios: 10 servicios con grupo (Visibilidad/Escala/Rentabilidad)
- Manufactura_FAQ: 4 preguntas frecuentes
- Negocios_Servicios: 4 bloques de servicios para negocios latinos
- Nosotros_Equipo: miembros del equipo (pendiente de fotos/bios)
- Leads: todos los leads de ambos formularios (campo "unidad" los diferencia)
